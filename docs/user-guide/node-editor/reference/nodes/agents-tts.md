# Voice Agent Nodes

Text-to-speech through the voice agent: resolve voices (including the narrator's), unpack voice data and generate speech, and read or rewrite the text of a chunk before it is spoken.

[Unpack Generation Emission](#unpack-generation-emission) and [Set Chunk Text](#set-chunk-text) belong in an event module listening for `agent.tts.generate.before`, which fires once per chunk of text right before its audio is generated. [Text Manipulation](../../../agents/voice/text-manipulation.md) walks through the setup.

!!! example "Reading the chunk"

    - `<Event>.event` :material-transit-connection-horizontal: `<Unpack Generation Emission>.emission`

    The `text`, `character_name`, `type`, `api`, `message_id` and `voice` outputs describe the chunk the agent is about to send to the backend.

!!! example "Rewriting the text"

    - `<Unpack Generation Emission>.text` :material-transit-connection-horizontal: `<Replace>.string`
    - `<Unpack Generation Emission>.emission` :material-transit-connection-horizontal: `<Set Chunk Text>.emission`
    - `<Replace>.result` :material-transit-connection-horizontal: `<Set Chunk Text>.text`
    - `<Make Bool>.value` :material-transit-connection-horizontal: `<Set Chunk Text>.state`

    The backend reads the chunk after the event, so the replaced text is what gets spoken. Writing empty text does not cancel the generation.

## Audio Tag Support

`agents/tts/AudioTagSupport`

Whether the voice backend of a chunk accepts sound tags such as [laugh]
or [sigh], and which ones. Use it on agent.tts.generate.before before
adding a tag with Set Chunk Text.

**Inputs**

| Input | Type | Description |
| --- | --- | --- |
| `emission` | `event,tts/generation_emission` | The generation emission |
| `tag` | `str` | A tag name to format for this backend, e.g. laugh (optional) |

**Outputs**

| Output | Type | Description |
| --- | --- | --- |
| `emission` | `tts/generation_emission` | The emission, passed through |
| `supported` | `bool` | True when the backend and model accept sound tags |
| `allowed_tags` | `list` | The tags the backend accepts, or None when any tag is accepted |
| `tag_format` | `str` | How a tag is written for this backend, with {{ tag }} for the name |
| `formatted_tag` | `str` | The tag input written in the backend's format, or None when the backend does not accept it |

**Properties**

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `tag` | `str` | `""` | A tag name to format for this backend |

## Generate TTS

`agents/tts/Generate`

Generates speech audio for the given text via the TTS agent and queues
it for playback in the frontend. Either a voice or a character must be
provided; when a character is given its assigned voice is used, while
an explicit voice input overrides it. Does nothing when the TTS agent
is disabled or not ready.

**Inputs**

| Input | Type | Description |
| --- | --- | --- |
| `state` | `any` | The graph state |
| `text` | `text` | (optional) The text to speak (required at runtime despite the optional socket) |
| `voice` | `tts/voice` | The voice to use (optional) |
| `character` | `character` | The character to speak as (optional) |

**Outputs**

| Output | Type | Description |
| --- | --- | --- |
| `state` | `any` | The state input, passed through |

**Properties**

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `text` | `text` | `unset` | The text to generate |

## Set Chunk Text

`agents/tts/SetChunkText`

Replaces the text of the chunk carried by a TTS generation emission,
letting a graph rewrite what is spoken before the audio is generated.
Empty text still reaches the backend and produces no audio for that
chunk.

**Inputs**

| Input | Type | Description |
| --- | --- | --- |
| `state` | `any` | The graph state (required — wire through any gating switch so the node is skipped when the chunk should be left alone) |
| `emission` | `event,tts/generation_emission` | The generation emission |
| `text` | `str,text` | (optional) The text to speak instead (required at runtime despite the optional socket) |

**Outputs**

| Output | Type | Description |

**Properties**
