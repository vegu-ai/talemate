### Update Agent Setting (update_agent_setting)

Change one agent setting. Use setting 'enabled' to toggle the action itself on or off. Scope 'global' changes the value for all scenes; scope 'scene' writes a per-scene override for the currently loaded scene.

You may call this function multiple times. 

#### update_agent_setting arguments

```json
{
  "function": "update_agent_setting",
  "arguments": {
    "agent": "str - Agent type.",
    "action": "str - Action key as returned by read_agent_settings.",
    "setting": "str - Setting key within the action, or 'enabled' to toggle the action.",
    "value": "str | int | float | bool | list - The new value. Must be valid for the setting's type and choices. For flags settings pass the FULL new list of values.",
    "scope": "str - 'global' or 'scene'."
  }
}
```

#### update_agent_setting examples

```json
{
  "function": "update_agent_setting",
  "arguments": {
    "agent": "conversation",
    "action": "generation_override",
    "setting": "length",
    "value": 192,
    "scope": "global"
  }
}
```
